## 🌐 Web version / Веб-версия / גרסת רשת — https://andyb1ack.github.io/hang-glider-sim-builds/

**EN:** Play in the browser on any phone (iPhone too) or computer, no APK needed. Add it to the home screen — full screen like an app, updates itself. Android: Chrome → ⋮ → “Install app”. iPhone: Safari → Share → “Add to Home Screen”.

**RU:** Играй в браузере на любом телефоне (и на iPhone) или компьютере, без APK. Добавь на главный экран — во весь экран, как приложение, обновляется сама. Android: Chrome → ⋮ → «Установить приложение». iPhone: Safari → «Поделиться» → «На экран “Домой”».

**HE:** משחקים בדפדפן בכל טלפון (גם באייפון) או במחשב, בלי APK. הוסיפו למסך הבית — מסך מלא כמו אפליקציה, מתעדכן לבד. אנדרואיד: Chrome ← ⋮ ← „התקנת אפליקציה”. אייפון: Safari ← שיתוף ← „הוספה למסך הבית”.
